## 工作台使用说明

- **成果概览**：看当前运行、任务编排与下一步；交付后直接打开预览或下载ZIP，长验收清单按需展开。
- **需求与审批**：看“待你审批”的具体版本，先读正文；可展开与上一版差异，填写修改意见后批准或要求修改。历史版只读，草稿绑定原审批ID。
- **开发协作**：点“查看…执行详情”查看任务范围、尝试链、工具与日志、集成与版本。工具执行成功不代表整个项目已交付，旧尝试和未知结果会单独标注。
- **质量验收**：按候选与SHA查看构建、QA、初审/终审；展开逐项AC、截图、具体缺陷与日志。测试资产修订仅在后端允许时可操作，产品缺陷须走源码修复。
- **执行记录**：看所选运行或整个项目的历史；阅读时新事件不会把旧记录顶走，点“有新记录”后再更新。
- **运行控制**：暂停/取消需要等待处理完成；“核对”不调用模型，“继续”可能产生费用。没有可信恢复证据时说明阻塞，不自动重试unknown。
- **模型配置**：全局默认→全局角色→项目默认→项目角色覆盖依次提高优先级；已有执行固定原修订。需要改变暂停的运行时，使用工作台里的版本化切换申请。
- **连接状态**：实时连接、查询同步、离线、重连与更新时间单独展示；连接问题不会把运行改成失败。恢复后按持久游标补查。预览需要本机预览服务，ZIP独立可运行。
