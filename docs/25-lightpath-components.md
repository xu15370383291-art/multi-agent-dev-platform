# B「光路编排」组件升级

用户选定组件概念 B。本轮保留 docs/24 的架构、五分类、操作与审批合同，只调整组件视觉和反馈。概念图中的搜索、聊天、用户账户、预计完成时间等示意内容不作为新增能力。

设计：深板岩 #20272E、烟蓝 #2D3944、铜光 #D9A16A、冰白 #B8D3DF、海绿 #7FAEA8、正文 #EEF0E8。标题使用系统中文无衬线与 Bahnschrift，正文 Segoe UI/微软雅黑，任务编号 Consolas。保留窄栏—项目条—编排画布—右侧操作—底部记录布局。识别元素为依赖线上的单束信号，面板磨砂和按钮反光服务于这一个主题。

评审：不把所有卡片做成持续呼吸灯，不在未开始或暂停的任务上流光，不用发光表示成功。完成、待核对、失败继续有明确文字。信号只指向当前运行中且状态为 active 的节点；其他连线静止。审批按钮保留查看正文和原版本化确认步骤。减少动态效果偏好、手机布局和键盘焦点须保留。

| 要求 | 实现 | 验证方式 |
| --- | --- | --- |
| 组件质感与按钮反馈 | 独立 lightpath.css，既有语义元素 | 构建、真实桌面/手机截图与键盘焦点 |
| 信号与状态一致 | WorkflowCanvas 连线、端口、运行态 | running/paused/completed/unknown 显式夹具，减少动态效果 |
| 保留审批、预算与数据 | 不改后端和请求处理 | 原前端测试及只读真实页面检查 |

## 实施结果与证据

- `frontend/src/lightpath.css` 统一磨砂面板、铜光按钮三态、分段分类栏、状态胶囊、审批面板、表单、模型设置和手机卡片；不新增组件库或外部字体依赖。主题由 `main.tsx` 在布局样式之后导入。减少动态效果和强制颜色模式均有覆盖。
- `WorkflowCanvas.tsx` 保留真实 DAG 箭头、候选版本和旧导航。SVG 为连线增加端口；仅在运行状态为 running 且目标为实际 active 开发节点时生成流光，其余为静态依赖线。暂停或结束但任务状态仍为 running 时继续显示“执行状态待核对”。完成状态用文字和静态海绿边区分，不用持续动画。
- `npm run build` 通过：CSS 32.12 kB / gzip 7.92 kB，JS 437.11 kB / gzip 136.62 kB。
- 完整前端 Playwright **48 passed，53.6 秒**，0 失败/跳过。证据 `.local/lightpath-tests.xml`、`.local/lightpath-tests.log`。原 42 项审批版本、模型配置、历史交付、文档等回归保留，新增 6 个桌面/手机夹具场景验证 running/paused/succeeded 状态、不为 unknown 流光、键盘焦点及减少动态效果。夹具不作为真实项目运行证据。
- 只读真实 Edge/API 检查 **10 个上下文通过**：5 个现有项目 × 1440/390，五分类、节点导航与缩放、模型设置、密钥输入为空、页面无溢出/异常、无写请求。脚本 `frontend/scripts/production-console-live.mjs`，独立归档 `.local/lightpath-live/live-results.json`，同目录有各项目概览/文档/模型截图；目视检查实际桌面与手机截图。
- 检查过程中新增夹具最初漏传 partition 导致页面渲染错误，补齐后剩余 3 项失败为测试直接在鼠标交互后调用 focus 未切换键盘模式，无法触发浏览器 focus-visible；改为先 Tab 再聚焦，保留焦点样式断言。最终全套重跑通过。预算耗尽的计量条在新主题中恢复铜色，未改预算数值。

本轮新增项目模型调用 0；未启动、批准、取消或恢复业务运行，未修改 API、数据库、审批版本合同、预算和执行隔离，未重新运行后端测试。概念稿的搜索、账户等没有复制成假入口。静态截图不作为动效证据，动效状态由自动化检查。此工作不等于 M2/M4 完成。
