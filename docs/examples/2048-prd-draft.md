# 2048 首个验收项目 PRD 草案

状态：验收样例草案，未获用户审批；不预填平台审批记录。

## 范围

单人浏览器版 2048。建议 TypeScript + Vite + DOM/CSS，无后端、账号或微信平台适配。持久化最高分使用 localStorage；存储不可用时仍应能继续游戏。

| 需求 | 验收标准 |
| --- | --- |
| REQ-001 棋盘与移动 | AC-001：4×4 棋盘；箭头键和 WASD 控制方向；无效移动不生成新方块 |
| REQ-002 合并规则 | AC-002：同值方块沿方向合并，每块每次移动最多合并一次；例如 [2,2,2,2] 向左变成 [4,4,0,0] |
| REQ-003 方块生成 | AC-003：初始两个方块，每次有效移动后在空位新增一个 2 或 4；随机性可在测试中注入确定性来源 |
| REQ-004 分数与记录 | AC-004：合并分数累加为新方块值；最高分刷新后保留；异常存储不阻断玩法 |
| REQ-005 结束与重开 | AC-005：满盘且四方向均不可移动时提示结束；重新开始重置本局但保留最高分 |
| REQ-006 手机操作 | AC-006：触摸滑动可移动棋盘，不因普通页面滚动重复触发；小屏不横向溢出 |

## 开发与检查证据

游戏规则单元验证、生产构建、浏览器输入与重开验收、存储异常用例、同候选 SHA 的 QA 和 Reviewer 报告，以及能按说明启动的源码包。

以上是未来平台生成项目的验收示例，本轮未生成游戏，也未声称这些标准已经通过。
