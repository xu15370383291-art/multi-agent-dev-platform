## 实施顺序

1. 增加质量与交付持久记录、迁移、版本绑定 schema 和只读 API。
2. 建立断网、非 root、限额 Docker Chromium/Playwright 环境；候选源码和构建摘要检查，测试资产与截图独立保存。业务代码不在宿主机执行。
3. QA 子流程生成测试并真实运行，Reviewer 独立只读审查；未知执行结果隔离、失败不自动放行。串行质量流程属于 M1，M3 并行与自动修复仍保留后续阶段。
4. 实现交付 gate、确定性文件包含规则、秘密文件拒绝、manifest 和隔离静态预览；接入工作台。
5. 测试通过与拒绝路径：缺 AC、未验证、错 SHA、旧报告、阻断审查、路径与秘密文件、重复请求、未知结果、取消/预算、构建错误、浏览器断言失败。
6. 重启本项目空闲服务，使用既有真实模型配置，建立正式 2048 项目。用户已授权本轮代理执行审批；逐项阅读文档后提交决定，不预填批准记录，不降低需求。
7. 按用户最新决定，使用 Playwright 操作真实工作台与正式交付预览，并核验 ZIP 摘要及按说明独立启动的静态包。以验收矩阵覆盖场景，不声称穷尽所有可能的软件状态。发现缺陷修复平台或让开发生成新候选后重新完整验证，旧报告不复用为新 SHA 证据。
8. 更新验收报告、README、启动说明及实际通过/未完成台账。M1 全部门槛通过后才能标记完成。

## 边界

保留原预算、审批、密钥存储和 Docker 隔离。QA 测试与业务代码均不获得宿主机路径、Docker socket、模型密钥。Reviewer 无写工具。交付预览与工作台分属不同来源，控制端拒绝预览来源请求。自动 DAG 并行、冲突修复、完整恢复控制台、SSE 属后续里程碑，不借本轮宣称 V1 完成。

critical/major 按 docs/04 默认阻断；本轮不增加豁免入口。预览按需读取已发布静态包，无每项目常驻进程，随预览服务停止失效；交付文件本轮保留，不自动删除。

真实 QA 联调补充：模型测试代码可能违反 Playwright API，因此增加由操作者逐次明确发起的测试资产修订（每次至少须剩余QA和Reviewer的2次调用，始终受原30次总预算约束），不是自动修改业务源码。必须是同一已构建候选/批准基线、旧 QA/Reviewer 均已知终态、全部质量工具已登记成功完成、失败仅属于已识别的测试 API 用法且没有源码 critical/major。产品断言失败、未知/超时工具、已交付、旧报告ID、预算不足均拒绝。请求不重置原运行计数，只新增 QA/Reviewer 报告行（attempt/supersedes），旧行及快照不变；模型只返回指定旧用例的完整脚本补丁，不允许改AC/name或删除其他用例，随后全部用例重新实际运行，Reviewer 读取新旧测试和结果独立审查。交付 gate 只接受最新同轮次报告、同SHA与明确QA报告ID绑定；旧报告摘要和失败结果随交付保留。源码自动修复、新候选循环及通用故障重试仍为 M3/M2 未实现项。

修复环境后的明确重验入口复用原模型生成的测试资产，不产生新的QA生成调用；同SHA、脚本字节/hash和断言全部保留，新建QA报告并重新执行预检/构建/全部浏览器用例，再由真实模型独立审查。仅接受已知完成的case_timeout且无产品断言失败/源码阻断问题，须更换已固定的验证镜像；未知工具、工具超时、旧ID、同镜像、已交付或原预算不足均拒绝。请求和Worker均核对镜像并绑定所有质量工具，旧失败报告保留。QA原资产来源ID写入报告。至少保留1次原模型预算用于Reviewer，不重置计数、不新建开发任务、不弱化交付gate。此为平台环境修复后的原资产重验，不是M2通用未知恢复或M3源码自动修复。

开发联调补充：工具参数在执行前被 schema 拒绝时，记录失败 ToolExecution、计入工具预算并反馈当前工具的 schema/示例，绝不执行非法请求。write_files 支持最多8个文件的受限批量写入，全部路径先验证，参数/日志不保存源码内容；每次模型调用提示原运行剩余额度，保留质量阶段预算。工具消息提供真实调用回执；完成结果引用错误最多再纠正一次，失败不计为完成。

狭窄人工核对入口仅接受旧参数 ValidationError 或完成结果的检查引用错误：快照摘要有效、批准基线不变、无活动容器、原预算仍有剩余，保留旧执行身份和模型快照、不重放初始化、不重置预算。旧 ValidationError 仍要求历史工具全部成功。仅检查引用错误可另接受明确的执行前参数拒绝，或已持久化执行后快照且未超时/未截断的非零命令退出；这些动作保留失败记录，不重放。未知结果、超时、缺失快照、活动执行、预算耗尽均拒绝。若父图已将该已知拒绝记录为暂停终点，Worker 必须在原租约锁下核对同一批准文档、单次核对令牌、无候选和原检查点，才从架构审批后的开发边重新进入；不重新审批或重跑规划。此项不是完整 M2 对账/恢复控制台。
